# E9, the lesson-design follow-up to E8: plan draft for Chris's approval (2026-09-10; NOT frozen, NOT registered)

E8 found that wiring the repair loop's failures into the memory store bought nothing and lost ground in one class. The exploratory note offered two explanations. The first is that the lesson text was misleading: it carried the latest failure's parameter (a specific banned letter), which was the wrong letter on most later prompts. The second is that any block injected ahead of a repair prompt dilutes the specific feedback the loop depends on, whatever the block says. E9 is built to tell them apart, on a task family with room to move, before anyone writes the wire off or fixes it by guesswork.

## What changes from E8

Three things. The task family drops the three classes that sat at 100 percent for every organ arm (lowercase, bullet lines, ending phrase) and hardens the rest, so the repair arms have room. Every class keeps six parameter values instead of many, so the same parameter recurs about four times in the sequence and a lesson keyed on a parameter has something to recall. And the wire comes in three designs, run side by side, so the two explanations make different predictions.

## Arms

Six arms. Haiku 4.5 through Bedrock, temperature 0.7, maxTokens 400, at most four generations per task, each arm and repetition in a fresh process, the kit's first-shot suffix on every first attempt, no shared drafts.

1. Base. One generation per task.
2. Repair only. The E8 stack with an empty store that nothing writes to. Both organs present, no wire.
3. Wire A, the E8 template. One lesson per class, replaced on each first-attempt failure, carrying the latest failure's measurement and requirement, parameter included. This is the replication arm: E8's loss should show again if it was real.
4. Wire B, parameter-free. One lesson per class, replaced on each first-attempt failure, carrying only the class name, the running failure count and the direction of the misses, computed from the violations (too long by 9 words on average; too many sentences by 2 on average; the banned letter appeared 6 times on average). No task's target, letter or word appears in it.
5. Wire C, parameter-keyed. One lesson per class and parameter. The cue is the parameter phrase exactly as it appears in the prompt (exactly 40 words; exactly 5 sentences; the letter "m"; exactly 3 commas; "river" exactly 4 times), so the lesson is recalled only on prompts with the same parameter. The content is the E8 template, which on a matching prompt is now the right specific.
6. Supplied rules. The E8 stack with the five hand-written E8 rules for these classes pre-loaded and nothing written during the run. The ceiling, as in E8.

The monolithic arms are not repeated: E8 measured them on this kind of family (organ arms 18 to 21 points above the system prompt, level with best-of-four), and E9's budget goes to the wire designs.

## Task family

Five classes, twenty-four prompts each, 120 prompts, each on its own topic from the E8 pool, generated by the E8 generator with new templates and parameter sets from seed 20260911, frozen as tasks-e9.json. Six parameter values per class.

| Class | Cue | Template | Parameters |
|---|---|---|---|
| wordcount | Word count | Write about {topic}. Word count: exactly {N} words. | N in {20, 30, 40, 50, 60, 75} |
| sentences | sentences | Write about {topic} in exactly {n} sentences. | n in {3, 4, 5, 6, 7, 8} |
| noletter | without using the letter | Write a short paragraph about {topic} without using the letter "{L}" anywhere in your response. | L in {c, d, l, m, p, s}, never a letter of the topic |
| commas | comma | Write a short paragraph about {topic} that uses exactly {n} comma(s) / that uses no commas at all. | n in {0, 1, 2, 3, 4, 5} |
| frequency | Use the word | Write a short paragraph about {topic}. Use the word "{w}" exactly {n} times. | w in {river, window, ladder}, n in {3, 5} |

Checkers are the E8 checkers unchanged (exact word count replaces the window). The E8 guards run before freezing: own cue present, no other class's cue anywhere, no cue in a topic, six parameter values per class, twelve prompts of each class in each half.

## Sequence

One fixed order for every arm and repetition, built as in E8: a seeded shuffle within each class, twelve prompts to each half, each half shuffled. Positions 1 to 60 form the store; positions 61 to 120 are where the lessons are measured. Three repetitions, differing only by sampling.

## Outcomes

Primary: Wire B minus repair only, pass rate on positions 61 to 120, per prompt averaged over repetitions, percentile bootstrap over the 60 prompts (2,000 resamples, seed 12345, alpha 0.05). This is the design E8's note proposed first, and its sign separates the two explanations: if the misleading parameter was the problem, B sits above repair only; if injection itself dilutes the repair prompt, B sits at or below it. Kill rule: an interval including zero means no parameter-free wire earns its place on this family either, and the report says so.

Secondary, one Benjamini-Hochberg family at q = 0.05, same positions and estimator, six comparisons:

- Wire A minus repair only (does E8's loss replicate);
- Wire C minus repair only;
- Wire B minus Wire A and Wire C minus Wire A (does removing or keying the parameter recover the loss);
- Wire B minus supplied rules and Wire C minus supplied rules (how far from the ceiling).

Mechanism outcomes, reported with intervals but outside the family: first-attempt pass rate per arm on positions 61 to 120 (E8 saw the wire raise first attempts while lowering final passes), and the recovery rate, the share of first-attempt failures the retries recovered, per arm. Descriptive: the same comparisons on positions 1 to 60 and all positions; pass rate by class and arm; learning curves by block of twenty; calls and tokens; every lesson written with its position; the leakage check (no topic string, no response text, template match) on every lesson; for Wire C, how many prompts recalled a lesson at all.

## Predictions

If the misleading parameter explains E8: Wire A at or below repair only in the forbidden-letter class and level elsewhere; Wire B and Wire C above repair only, by a few points, mostly in word count, sentence count and comma count where the direction of a miss is informative; both above Wire A. If dilution explains E8: all three wires at or below repair only on final pass while at or above it on first attempts. Supplied rules at or above every wire. The family is expected to have room: repair only between 70 and 90 percent overall.

## Void conditions and disclosure

As in E8: void and rerun in full, with the reason disclosed, if any arm's call errors exceed one percent, if a checker is found wrong for its stated definition, or if a child process fails. The scripted-fake smoke test runs before the freeze and is not data. The same assistant wrote the organs, the harness, the lesson templates and the rules, and the plan says so.

## Registration, cost and reporting

A second public registration from the same OSF project (Open-Ended Registration, CC BY 4.0, public immediately) with the plan, the frozen task list and the code in a folder e9-composition-pilot, before any call. At most 120 x 3 x 6 x 4 generations, about 3,600 calls in practice, under ten dollars, about an hour to run.
